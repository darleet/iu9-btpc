# Полный список OPCodes

## Аритметика / сравнения / логика

- OPAdd (0) — сложение; a b → (a+b)

- OPNeg (1) — унарный минус; a → (-a)

- OPMul (2) — умножение; a b → (a*b)

- OPDivD (3) — целочисленное деление; a b → (a div b)

- OPRemD (4) — остаток; a b → (a mod b)

- OPDiv2 (5) — оптимизация: деление на 2; a → (a div 2)

- OPRem2 (6) — оптимизация: остаток по 2; a → (a mod 2)

- OPEqlI (7) — a = b → 0/1

- OPNEqI (8) — a <> b → 0/1

- OPLssI (9) — a < b → 0/1

- OPLeqI (10) — a ≤ b → 0/1

- OPGtrI (11) — a > b → 0/1

- OPGEqI (12) — a ≥ b → 0/1

- OPAndB (15) — булевый оператор AND; a b → (a and b)

- OPOrB (16) — булевый оператор OR; a b → (a or b)

## Операции над стеком

- OPDupl (13) — дублировать вершину; x → x x

- OPSwap (14) — поменять местами 2 вершины; a b → b a

## Память: по адресу (указатели)

- OPLoad (17) — загрузка *addr; addr → value
(берёт адрес с вершины стека, читает 4 байта по нему, пушит значение)

- OPStore (18) — запись *addr = value; value addr → ·
(снимает значение и адрес, пишет 4 байта по адресу)

## Ввод/вывод и служебные

- OPHalt (19) — немедленное завершение программы (exit)
(в PE вызывает ExitProcess, в VM — завершение интерпретации)

- OPWrI (20) — вывести целое (без перевода строки); x → ·

- OPWrC (21) — вывести символ; x → ·

- OPWrL (22) — вывести перевод строки; · → ·

- OPRdI (23) — прочитать целое; · → x

- OPRdC (24) — прочитать символ; · → x

- OPRdL (25) — прочитать до конца строки; · → ·

- OPEOF (26) — EOF? → 0/1

- OPEOL (27) — EOLN? → 0/1

## Константы и адреса (имеют imm32)

- OPLdC (28) + imm32 — положить константу; · → imm32

- OPLdA (29) + imm32 — global address &G[imm]; · → addr
(по сути это LEA EAX,[EBP+imm])

- OPLdLA (30) + imm32 — local address &L[imm] (относительно кадра); · → addr.
(по сути это LEA EAX,[ESP+imm])

## Локальные/глобальные (адрес+загрузка/запись)

- OPLdL (31) + imm32 — загрузить L[imm]; · → value
(эквивалент OPLdLA imm; OPLoad)

- OPLdG (32) + imm32 — загрузить G[imm]; · → value
(эквивалент OPLdA imm; OPLoad)

- OPStL (33) + imm32 — L[imm] := value; value → ·
(эквивалент OPLdLA imm; OPStore)

- OPStG (34) + imm32 — G[imm] := value; value → ·
(эквивалент OPLdA imm; OPStore)

## Блочные операции (структуры/массивы)

- OPMove (35) + imm32(size) — memmove(dst, src, size); src dst → ·

- OPCopy (36) + imm32(size) — memcpy(dst, src, size); src dst → ·

## Арифметика с константой

- OPAddC (37) + imm32 — x → x + imm32

- OPMulC (38) + imm32 — x → x * imm32

## Переходы/ветвления (имеют imm32-цель)

- OPJmp (39) + imm32 — безусловный переход
(в исходнике пока цель хранится в координатах PC; при записи байткода конвертируется в rel32)

- OPJZ (40) + imm32 — if top==0 then jump; x → ·

## Вызовы и управление кадром

- OPCall (41) + imm32 — вызов подпрограммы.
В btpc: вызывающая сторона кладёт (для функций) return-slot, затем аргументы, и static link (если вложенная); OPCall прыгает в код функции

- OPAdjS (42) + imm32 — сдвиг кадра (выделение/освобождение locals):
ESP := ESP + imm32 (знак +/- по смыслу).
Используется в прологе/эпилоге блоков и функций

- OPExit (43) + imm32 — возврат из функции с очисткой параметров:
снимает со стека imm32 байт (аргументы + static link), возвращаясь к вызывающему.
Результат функции записывается телом функции в заранее приготовленный return-slot у caller

## Специальные

- OPNone (-1) — пусто/нет операции (служебное).

---

### Быстрые заметки по стеку и адресам

- Все значения — 32-битные (int/ptr/bool/char)

- OPLdA/OPLdLA кладут адрес, OPLoad/OPStore — работают по адресу

- OPLdL/OPLdG и OPStL/OPStG — это формы "адрес + (load/store)"

- OPAddC/OPMulC, OPDiv2/OPRem2 — оптимизации на стадии генерации

- OPAdjS реализует ENTER/LEAVE логику (зарезервировать/освободить locals)

- OPExit не трогает return-slot: тело функции само писало туда результат через OPStore
