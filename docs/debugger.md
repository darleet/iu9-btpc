# BTDB - Отладчик для BTBC

Простой консольный отладчик для байткода BTBC виртуальной машины btvm.

## Сборка

```bash
cd src/vm
cc -O2 -std=c11 -Wall -Wextra -pedantic -o btdb btdb.c
```

Или с помощью make из корневой директории проекта:

```bash
make debugger
```

## Использование

```bash
./btdb program.btbc
```

Опции:
- `--stack <bytes>` - размер стека в байтах (по умолчанию 8 МБ)

## Команды отладчика

После запуска отладчик показывает текущую инструкцию и ожидает команды:

### Основные команды

- `s` или `Enter` - **Step** - выполнить одну инструкцию
- `c` - **Continue** - продолжить выполнение до точки останова или завершения
- `r` - **Registers** - показать регистры (PC, SP, EBP)
- `q` - **Quit** - выйти из отладчика
- `h` или `?` - показать справку

### Просмотр состояния

- `t [count]` - **sТack** - показать стек (по умолчанию 8 значений)
  - Пример: `t 16` - показать 16 значений со стека

- `m <addr> [count]` - **Memory** - показать память по адресу
  - Пример: `m 0 16` - показать 16 байт памяти начиная с адреса 0
  - Адрес указывается в шестнадцатеричном формате

- `i [addr] [count]` - **dIsassemble** - дизассемблировать код
  - Пример: `i` - дизассемблировать с текущего PC (10 инструкций)
  - Пример: `i 20 5` - дизассемблировать 5 инструкций начиная с адреса 0x20

### Точки останова (breakpoints)

- `b <addr>` - установить точку останова по адресу
  - Пример: `b 10` - установить breakpoint по адресу 0x10

- `l` - **List** - показать список всех точек останова

- `d <num>` - **Delete** - удалить точку останова по номеру
  - Пример: `d 1` - удалить первую точку останова

## Пример работы

```
$ ./btdb test.btbc

BTBC Debugger - type 'h' for help

=>   0000: OPLdC     42 (0x2a)

(btdb) r

Registers:
  PC  = 0 (0x0)
  SP  = 8388604 (0x7ffffc)
  EBP = 0 (0x0)

(btdb) t 4

Stack (SP=8388604, count=4):
  [7ffffc] = 0 (0x00000000)

(btdb) s

=>   0005: OPWrI     1 (0x1)

(btdb) t 4

Stack (SP=8388600, count=4):
  [7ffff8] = 42 (0x0000002a)
  [7ffffc] = 0 (0x00000000)

(btdb) b 10

Breakpoint 1 set at 0x10

(btdb) c
42
*** Breakpoint 1 hit at 0x10 ***

=>   0010: OPHalt   

(btdb) s

*** Program halted with exit code 0 ***
```

## Возможности

- Пошаговое выполнение инструкций
- Точки останова (до 64 точек)
- Просмотр регистров, стека и памяти
- Дизассемблирование кода
- Режим непрерывного выполнения до breakpoint
- Поддержка всех инструкций BTBC
